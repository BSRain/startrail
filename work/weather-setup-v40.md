# 星迹 4.0 天气设置

1. 覆盖安装 startrail-4.0-debug.apk。
2. 打开“观测” → “天气观星计划” → “和风天气 · JWT 配置”。
3. 本个人体验版已预填此前提供的 Host、开发者 ID、项目 ID、凭据 ID，核对后点“保存配置”。
4. 将你保管的私钥 PEM 文件放到手机可选取的位置，点“导入 Ed25519 私钥文件”，选择与和风已登记公钥配对的文件。不要选择公钥文件，也不要发送私钥给别人。
5. 显示“私钥已导入”后关闭配置。首次真实请求会验证认证和接口权限，成功后展示获取时间与天气数据。
6. 确认观测地点。需要时点“调整时段与地点” → “更新手机定位”，完成后重新打开计划。默认北京仅为示例。
7. 选择日期和空闲时段；可加入清单或预览指定时刻。时间按设备时区显示。

401 请检查公私钥是否配对、各 ID 及手机时间；403 检查小时预报权限；429 等待后重试并检查额度。无天气数据时可继续使用标注为“仅天文候选”的离线结果。

删除私钥会关闭天气请求。普通手记备份不包含天气私钥。截图中的天气为标记过的测试样本，不是真实天气预报。
