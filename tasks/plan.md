# 4.3 天象日历计划

目标：本地天象目录 → 按观测地点/暗夜/逐小时天气评估 → 推荐观测时间 → 系统日历确认预约。使用真实时间，不使用星图模拟时间。

范围：日月食（红月为月全食）、四个主要月相、月球与五颗肉眼行星近距离相会、肉眼行星相会、主要流星雨目录。相会定义为视角距离极小值，不把它冒称赤经合。流星雨数据明确来源、适用年与不确定性。浏览未来30/90/365天。

架构：纯 Java CelestialEvents 提供事件，EventObservationPlanner 提供地点/天气候选，EventCalendarDialog 异步加载及筛选，CalendarBooking 使用 ACTION_INSERT 打开系统日历。主 Activity 只接入口与生命周期。

约束：太阳事件可在白天评估且明确安全提示；月食只在实际食相窗口评估；近距离相会要求双方在地平线上；天气缺失不等于晴天，已知恶劣天气不降级绕过否决。预约不自动保存、不声称已设置提醒、不自动改期。不访问真实用户天气凭据做开发测试，不提交任何私钥。

验证：天文参考事件/日界与边界、晴雨未知/地点不可见、日历UTC时间与跨日、取消/后台/陈旧响应、Android回归及签名。新功能在独立分支实现，完成后提供可覆盖升级的4.3安装包。
