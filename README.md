# 星迹 StarTrail 4.1

面向观星新手、星图离线且天气可选联网的 Android 应用：将手机背面朝向天空，3D 天球随手机转向、俯仰和侧倾更新，并根据地点和时间显示天体位置。

## 4.1 工程整理

- MainActivity 拆出文件备份控制器、目录/收藏弹窗、帮助/许可页面；共享控件由 DialogUi 构建。
- 主页面与天气页面的 UI 文案移到 Android 字符串资源，关键动态文案使用占位符；本版仍以中文为主，并未提供完整外语翻译。
- 自定义 View 构造函数与自动备份/设备迁移排除规则完善。同步保存用于确认失败及回滚，保持原语义。
- 全新安装不再内置个人和风账号标识。覆盖升级保留已保存的天气配置和私钥；未曾保存的旧版默认值需手动填写。
- 本地 Git 仓库从本版建立。参见 VERSION_CONTROL.md。
- 可覆盖旧版的交付为 debug APK，沿用原证书；正式 release 签名从外部配置读取。没有正式密钥时只生成不可直接安装的 unsigned APK，不会自动套用调试签名。详见 RELEASE.md。

## 4.0 天气观星计划

观测页 → 天气观星计划 → 和风天气 JWT 配置。4.0 个人体验版曾预填账号标识；4.1 全新安装需手动填写 Host、开发者 ID、项目 ID 和凭据 ID，不包含私钥或 Token。保存配置后，通过系统文件选择器导入与和风公钥匹配的 Ed25519 PKCS#8 PEM 私钥。关闭配置页后生成计划。公共分发前应移除个人账号标识。

- 选择今天、明天或后天以及空闲时间，支持跨午夜；使用设备时区和真实日期，不使用星图模拟时间。默认北京是示例，先确认地点，或点击“更新手机定位”，定位后重新打开计划。
- 当前和风小时预报接口固定请求未来 72 小时，需相应接口权限。JWT 为 EdDSA，iss 为开发者 ID、sub 为项目 ID、kid 为凭据 ID，短期 Token 在请求时自动生成。
- 同地点预报内存缓存 30 分钟，手动刷新立即更新。无后台请求。获取时间不等于预报发布时间。失败不使用旧预报。
- 请求向和风发送两位小数的观测经纬度及 JWT。私钥以 AndroidKeyStore 中的 AES/GCM 密钥加密保存，不进入 APK 或普通备份；可删除私钥关闭天气请求。
- 每 20 分钟交叉计算天色、目标高度、月光与天气；云量 >=80%、降水 >0.1 mm、风速 >=40 km/h 排除。湿度、风速及云量参与排序。最多五个候选按时间排列，可预览和加入清单。
- 全部天气缺失时提供明确标注的“仅天文候选”；部分缺失时优先用完整云量和降水数据。无合适时段会直接说明。
- 地平线下显示及原有离线星图、天文、手记功能保留。日月升落与曲线仍在目标详情中查看。
- 无天气预警、光污染模型或流星雨订阅；阈值是产品规则，不是可见度或气象安全保证。真实账户连接待用户导入私钥后验证。

接口与边界见 work/weather-sources.md。

## 3.9 观测助手

- 今晚推荐加入深空目标：要求太阳低于−18°且目标高于20°，有合格目标时至少保留一个深空名额；月球、行星和亮星仍按原规则推荐。附器材与月光提示，不把扩展天体的总星等当成肉眼可见保证。
- 天体详情、推荐卡片和观测清单可打开“高度曲线与升落时刻”，按所选时刻起未来24小时计算；支持太阳、月球、行星、恒星及深空目标。
- 展示首次升起、上中天和落下；曲线每10分钟采样，区分暗夜与白天/暮光，保留负高度。拖动曲线或滑块可选择时刻并跳回星图。
- 升落按几何中心穿过0°计算，不含折射、日月边缘或地形，不等同常见日出日落预报。事件时刻是近似值；窗口内无事件会明确显示，不强行给出时刻。接近2100年末时裁剪窗口。
- 独立观测清单支持加入、移除、标记完成和本机保存，最多200个目标，跨日期保留；不自动生成手记。入口在“观测”页。

## 3.7 平滑漫游

- 时间轴播放在两次天文快照之间补充逐帧运动，恒星、深空目标、银河与星座插画一起移动，地平线和方向网格保持本地水平参考。
- 正放和倒放均支持；暂停时以画面正在显示的时刻重新计算准确位置。天文计算继续采用120ms调度，不恢复每帧全量计算。
- 双指缩放切换到手动；抬起第一根手指后，剩余手指接续拖动不再使用旧指坐标，也不会把缩放识别为点击。
- 名称在四个候选位置间避让，可直接点击名称选中天体，较长名称按可用宽度省略。
- 补间模拟短间隔的周日运动，并非逐帧重算月球和行星轨道。画面最多通常落后一个120ms计算间隔；月球/行星自身运动和亮度仍随精确快照更新。大幅时间跳转直接定位。

## 3.6 性能与稳定性

- 背景星共享 J2000 → 本地天空的旋转矩阵，避免逐颗重复计算岁差与恒星时，保留原有坐标算法精度。
- 背景星去重在星表载入后准备一次，切换页面复用结果；绘制复用命中点、标签边框、渐变和地平线路径，深空类型和标签顺序提前计算。
- 时间轴播放计算间隔改为 120 ms，按实际经过时间推进，手机姿态绘制保持独立。3.7 在快照之间补充平滑运动。
- 3.6 新增 20 项纯 Java 本地测试；通用颜色抽为 AppPalette，导航和常用按钮文案移入 strings.xml。
- 性能对照见 work/performance-v36.md。这是模拟器 CPU 测量，不是实体手机帧率或耗电保证。

## 3.5 深空探索

- 新增 14 个深空目标，包括仙女座星系、猎户座大星云、昴星团、环状星云等，随地点、时间和视角更新。
- 搜索或观测页打开“深空目录”，按星系、星团和星云分类；支持名称、M/NGC 编号搜索、收藏与寻星。
- 五种符号区分天体类型；详情提供综合视星等、参考角尺寸和观测器材提示。符号不是照片，也不按真实视大小绘制。
- 深空图层默认开启，地平线下仍显示；关闭图层后，选中或正在引导的目标仍保留。
- 坐标与目录数据来源于 OpenNGC（Mattia Verga，CC BY-SA 4.0），参见 work/deepsky-sources.md。3.9 已将深空目标加入今晚推荐。

## 3.4 优先修复

星图默认显示地平线上下全部已收录天体，无需开启设置。恒星、背景星、太阳、月球、行星及星座连线不会因高度为负而隐藏；下半球保留半透明地面分区和提示，仍可点击与查看详情。搜索目标后点“在星图查看”可直接查看地平线下目标。实际观测清单和寻星对准判断仍依据真实地平线。

## 3.3 保留功能

- 我的收藏：天体详情一键收藏，在搜索或观测页打开列表，可查看详情、寻星和移除，按收藏顺序保存于本机。
- 手记导出：记录页通过系统文件选择器保存 JSON 备份，包含目标、时间、地点、经纬度和笔记。
- 手记恢复：先检查文件，再预览新增数量；相同记录 ID 保留本机版本，重复恢复不产生副本，取消不修改记录。
- 备份限制为 2 MiB / 2000 条，支持 1900—2100 年；无效文件整份拒绝。备份目前只覆盖手记，不含收藏、观测清单和设置。

## 3.2 保留功能

- 时间轴：当天拖动、日期跳转、正放/倒放、暂停、跨天和回到现在；速度为每秒 1 分钟、10 分钟或 1 小时。支持 1900—2100 年，按设备时区处理夏令时长短日。
- 银河背景：按真实银道坐标定位的原创柔和云雾与暗带，随时间、地点和视角移动。亮度为艺术化表现，不是摄影或可见度预测。
- 七组星座插画：天鹅、天琴、猎户、大熊、仙后、天蝎、飞马；原创矢量形象固定于相应天区。
- 图层：银河、插画、网格、星座连线、名称和红色夜间模式可分别设置，保存于本机。

## 3.1 保留功能

寻星增加中文动作提示和稳定对准后的轻微触感；信号不可靠时暂停确认。校准保存、取消回退和重启恢复补齐验证。夜间推荐增加每个目标的近似可观测时段、月光参考及月球/行星优先安排。触感遵循系统设置，实体手机精度和触感仍待实测。

## 已有重点功能

- 全屏星图：扩大观看面积，保留跟随、校准、搜索、时间轴和图层入口，返回键退出。
- 箭头寻星：搜索目标后点击“开始寻星”，自动使用当前真实时间；屏外显示方向箭头，进入画面后引导到中央准星，地平线下明确提示。
- 方向校准：新增水平微调（−30° 至 +30°）、本机保存与归零；磁场异常、精度较低或缺失数据会提示，方向流中断后回到手动模式。
- 今晚推荐：基于地点和所选时间，在未来 24 小时内取当前剩余夜间或下一夜间，筛选较高空的入门目标，可预览推荐时刻或现在寻星。时刻使用设备时区，推荐为近似值。

## 保留功能

- 3D 透视天球、地平线和方向网格；拖动环顾、双指缩放、手机姿态跟随。
- 83 颗具名恒星、31 条星座辅助连线、2865 条真实背景恒星数据（绘制时排除具名星附近重复点）。
- 太阳、月球、水星、金星、火星、木星、土星、天王星、海王星；离线计算位置，月球显示月相，土星带环。

- 名称和别名搜索、跳到目标方向、地平线上方清单、本机观星手记、红色夜间模式。

## 安装与使用

安装 outputs/startrail-4.1-debug.apk，支持 Android 8.0 及以上。本体验版与本项目已交付的 1.0 / 2.0 / 3.0 / 3.1 / 3.2 / 3.3 / 3.4 / 3.5 / 3.6 / 3.7 / 3.9 使用相同签名，可覆盖升级。首次打开请确认地点：北京是默认示例，不是自动检测的位置。

开启“跟随手机”，将手机背面朝向目标天空。远离磁性物体，并按“方向校准”提示画 8 字校准。拖动会切换为手动模式；再次点击跟随按钮即可恢复。无法获得方向传感器数据时会提示手动查看。陀螺仪提供转动信息，磁力和重力传感器帮助确定北向与水平；只有陀螺仪不能确定北方。

目标在地平线下时也在星图显示，并标明其位置；实际天空中仍被地球遮挡，可在详情查看高度。日月和行星图标经过放大，方便辨认。不要直视太阳。

## 从源码构建

使用 JDK 17、Android SDK 35 和 Android Studio 打开项目，或运行 ./gradlew assembleDebug（Windows 使用 gradlew.bat）。首次构建需联网下载 Gradle、Android 构建依赖及 JitPack 上的 Astronomy Engine 2.1.19；安装后的应用计算不需要网络。APK 位于 app/build/outputs/apk/debug/app-debug.apk。源码不含签名私钥，其他电脑自行构建的调试包会使用该电脑的签名。

纯数学测试无需模拟器：运行 ./gradlew :app:testDebugUnitTest。测试代码位于 app/src/test；优先使用 Gradle 发行包自带的 JUnit 4 / Hamcrest，其他发行包回退到标准 JUnit 依赖。完整构建首次仍需要 Gradle/Android SDK 依赖。

可在专用测试模拟器上执行 ./gradlew connectedDebugAndroidTest。测试包含手记增删并清空测试记录，不要在存有个人记录的设备上运行测试。

详细变更和本轮范围见 CHANGELOG.md。

## 数据、隐私与限制

这是三维坐标和透视投影绘制的天空视图，不含相机 AR、天气、建筑或地形遮挡。位置和传感器数据只在本机计算，手记只在本机保存；卸载会清除记录。地平线上方不等于肉眼可见，白天、云层和光污染会影响观测。

太阳系使用 Astronomy Engine 2.1.19（MIT）；背景数据来自 HYG v4.1（David Nash / astronexus，CC BY-SA 4.0），派生 CSV 采用相同许可。完整许可见 THIRD-PARTY-NOTICES.txt，应用“设置 → 使用说明与数据来源 → 开源许可”也可查看。来源见 work/astronomy-sources.md、work/solar-sources.md、work/starfield-sources.md、work/observing-sources.md。

恒星采用轻量岁差和地平坐标换算，省略恒星自行、章动、光行差等精密修正；太阳系包含光行差和月球观测地点视差。两者均不应用大气折射，不能用于望远镜精密指向。

129 项 Android 15 模拟器测试与 43 项本地 JVM 测试全部通过，覆盖新增观测时段、深空推荐、清单，以及地平线下显示、时间轴、收藏与备份等回归；Lint 0 错误、2 个警告。本轮验证结果见 VALIDATION.md。通过模拟器传感器注入确认实际星图随姿态更新。实体手机指南针、GPS 和户外体验尚待验证。详见 VALIDATION.md。

时间轴播放在打开弹窗、切换页面或应用进入后台时暂停；收起时间轴仍可继续播放，展开后暂停。星座插画为象征性构图，并非完整 88 星座边界。后续功能按 ROADMAP.md 继续推进。
